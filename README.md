# BrewDog USA — Test Automation Case Study

A standalone project website for the BrewDog USA automation framework
(https://github.com/raphaelbouskila148-code/brewdog-automation).

Built by Raphael Bouskila. Independent QA portfolio project — not affiliated with BrewDog.

## Files

    index.html          the whole page
    styles.css          the design
    assets/             portrait
    videos/             six recordings of real test runs, plus their poster frames
                        and three screenshots of the store under test

## Publishing on GitHub Pages

1. Create a public repository, e.g. `brewdog-automation-site`.
2. Upload everything in this folder (not the folder itself).
3. Settings -> Pages -> Source: Deploy from a branch, branch `main`, folder `/ (root)`.
4. The site goes live at
   https://raphaelbouskila148-code.github.io/brewdog-automation-site/

## Adding more test recordings

Put the .mp4 in `videos/`, then copy one of the six blocks in the
"Watch the tests run" section of `index.html` and change the file name,
the test IDs and the text.
